# Hi, I’m Shubham Jain

I build practical software products and open-source tools. I’m currently creating **PatchRover**, a local-first incident-response agent that tracks critical software vulnerabilities from advisory to source, container, and running workload.

## What I’m building

### PatchRover — Track. Fix. Prove.

PatchRover uses signed, declarative response packs and deterministic evidence to:

- identify affected repositories and workloads;
- prepare bounded remediation pull requests under explicit policy;
- submit bounded fixes for team approval; commercial customer runners can rotate allowlisted machine credentials through typed integrations;
- verify which fixed artifact is actually running;
- create redacted, independently verifiable closure receipts.

The project is Apache-2.0, local-first, and designed to fail closed when evidence is missing. It does not change human passwords, merge pull requests, or deploy production workloads.

## Principles
