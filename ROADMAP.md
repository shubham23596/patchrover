# Roadmap

## Open-source foundation

- Deterministic pack engine and four-state verdict model.
- Repository, SBOM, explicit OCI reference, and read-only Kubernetes evidence.
- Local remediation proposals, approval-gated pull requests, typed Vault database credential rotation, and integrity-verifiable receipts.
- Two public incident packs and reusable synthetic test fixtures.
- Local Ollama and explicit HTTPS BYOK explanation adapters with evidence-bound, non-authoritative output.
- Continuous structured CISA KEV, GitHub Advisory, and official RSS/Atom monitoring.

## Private design-partner beta

- Live OCI registry manifest and SBOM resolution.
- Organization-trusted Sigstore identities and registry transparency.
- More typed repository and machine-credential integrations without a generic shell or human-password capability.
- Cross-repository and cross-cluster trail correlation.

## Commercial control plane

- Private packs, continuous monitoring, an approval inbox, approved fix application, fleet inventory, drift alerts, history, SSO/RBAC, audit retention, and workflow integrations.
- The bounded open-source-agent submission bridge, team approval API, and customer-hosted GitHub/Vault runner are implemented; hosted staging and production-readiness gates remain open.
- The open-source CLI, public pack format, public post-disclosure packs, and receipt verifier remain public.

Commercial milestones are measured by repeat incident use and paid pilots, not GitHub stars alone. See [GOVERNANCE.md](GOVERNANCE.md) for project decision-making.
